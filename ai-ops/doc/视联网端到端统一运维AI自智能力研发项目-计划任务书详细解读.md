## 二、项目目标与任务

### 1. 核心目标:达到云网运营自智等级 L4

项目围绕集团云网运营自智能力评估标准,明确以下考核指标:

| 考核指标 | 目标值 |
|---------|-------|
| 割接自动化率 | ≥85% |
| 云网隐患/故障发现自动化率 | ≥70% |
| 巡检自动化率 | ≥80% |
| 云网事件(故障)自动处置率 | ≥50% |
| 质差问题根因自动定位比例 | ≥70% |
| 业务平台故障修复时长达标率 | ≥50% |

### 2. 四大核心能力建设

#### ① 智能化监控排障

- 基于AI能力提升故障隐患发现、识别、根因定位、修复方案生成及决策能力
- 实现闭环:**隐患自动发现 → 故障自动发现 → 根因自动定位 → 故障自修复**

#### ② 智能化巡检

- AI模型依托平台资源数据和端到端监控数据,生成**个性化巡检方案**
- 巡检异常自动生成处置建议并自动处置

#### ③ 智能化数据治理

- 资源数据和关联关系的**AI建模**;CMDB资源和跨层资源关联**自动发现**
- 多维度资源数据**自动比对和修正**

#### ④ 智能化割接维护

- 自动解析割接需求 → 自动生成割接方案 → 风险评估决策 → 自主编排执行 → 自动判定结果 → 异常自动回退

## 八、总结与关键观察

### 项目定位

典型的电信行业智能运维(**AIOps**)升级项目,以中国电信天翼视联业务为场景,目标明确指向集团 **L4级自智能力** 考核。

### 技术深度

项目采用多层次AI技术栈:

| 技术 | 应用场景 |
|------|---------|
| **大模型(Large Model)** | 需求解析、根因定位、报告生成 |
| **机器学习(分类/回归/聚类)** | 异常检测、隐患识别 |
| **图神经网络(GNN)** | 资源拓扑自动推导 |
| **知识图谱** | 变更策略库、故障知识库 |
| **强化学习** | 割接方案优化 |

### 潜在关注点

1. **周期偏紧**:6月启动、12月终验,半年内完成从需求到验收的全过程
2. **依赖外部委托**:核心开发工作外包,需严控交付质量
3. **指标差距**:技术考核指标中故障自动处置率>80%,而项目目标写的是≥50%,存在目标与考核的对齐空间
4. **数据质量**:效果高度依赖现有监控数据、CMDB数据的完整性和准确性
