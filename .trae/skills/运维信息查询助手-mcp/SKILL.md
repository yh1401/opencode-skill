# 查询运维信息助手-MCP

## 技能概述

本技能是 **「查询运维信息助手」的 MCP 版本**，用于 **CMDB 服务器配置信息查询**（cmdb-server-query）。

与直接调用 CMDB 业务系统的旧版本不同，**本版本通过 MCP 服务（cmdb-mcp-server）获取数据**：
- 平台侧：在 StarAgent 平台注册 MCP 服务 `cmdb-mcp-server`（服务地址 `http://localhost:5235/gateway/cmdb/mcp`）
- 技能侧：本技能只声明"调用哪个 MCP 工具 + 传什么参数"，由平台路由到已注册的 MCP 服务执行
- 数据源：MCP 服务内部转发到 CMDB 业务系统（`https://oss.tech.ctseelink.cn`），并处理超时、异常降级等

| 技能 ID | 功能描述 | 触发关键词 |
|---------|----------|------------|
| cmdb-server-query | 查询服务器配置信息 | 服务器、主机、机房、IP、公网IP、配置、硬件、CPU、内存 |

---

## 前置条件（MCP 服务注册）

> 部署 cmdb-mcp-server 并注册到平台后，本技能才能生效。部署步骤见 [cmdb-mcp-server 部署文档](../../../cmdb-mcp-server/deploy/deploy-guide.md)。

1. **部署服务**：在服务器执行 `./deploy-prod.sh`，确认健康检查返回 200
2. **平台注册**：在 StarAgent 平台注册 MCP 服务，填写服务地址 `http://localhost:5235/gateway/cmdb/mcp`
3. **验证工具**：平台应能发现 `cmdb_server_query` 工具（通过 MCP `tools/list`）

---

## 路由规则

当用户输入包含「服务器/主机/机房/IP/公网IP/配置/硬件/CPU/内存」等关键词且意图为查询服务器信息时，匹配 `cmdb-server-query`。

**业务处理**：参数映射、输出格式化等业务逻辑由子技能 [cmdb-server-query/SKILL.md](skills/cmdb-server-query/SKILL.md) 负责。

**排他条件**：
- 用户查询"部署/发布/上线"记录 → 暂不支持（MCP 服务已提供 `project_deployment_query` 工具，后续版本启用）
- 用户查询"产品信息" → 暂不支持（MCP 服务已提供 `product_query` 工具，后续版本启用）

## MCP 工具调用方式

本技能所有数据查询通过调用 MCP 工具完成，**不需要技能自身发起 HTTP 请求**。

### 工具清单

| MCP 工具 | 对应子技能 | 说明 |
|----------|-----------|------|
| `cmdb_server_query` | cmdb-server-query | 查询服务器配置信息（当前启用） |

### 调用约定

- **工具名**：`cmdb_server_query`（工具名必须与 MCP 服务 `tools/list` 返回的一致）
- **参数**：见子技能 SKILL.md 的「输入参数」章节，参数名/类型/可选值必须与 MCP 工具 schema 一致
- **调用方式**：通过平台的 MCP 工具调用机制（`tools/call`），由平台注入 MCP 工具供 Agent 使用

## 输出格式

### 标准输出（简单模式 - 默认，显示前 10 条）

```markdown
## 服务器查询结果

**查询条件**：{用户原始查询}

**查询范围**：{中文描述，如"机房=贵州，状态=在线"}

---

**结果摘要**：共查询到 N 台服务器（当前显示前 M 条）

---

| 主机名 | IP地址 | 机房 | 状态 | 类型 |
|--------|--------|------|------|------|
| 数据1  | 数据2  | 数据3 | 数据4 | 数据5 |

---

💡 您可以说："查看详细信息"获取 CPU/内存/操作系统等，或"下一页"查看更多
```

### 详细输出（用户要求"查看详细信息"时）

在简单模式基础上增加字段：CPU、内存、操作系统、环境、产品、项目。

---

## 上下文规则

多轮对话中保留以下参数（有效期 5 分钟）：
- 机房位置（node）
- 当前页码（currentPage）和每页条数（pageSize）
- 查询模式（simple/detail）

**继承规则**：用户未明确指定参数时自动继承上下文。

| 用户输入 | 处理逻辑 |
|----------|----------|
| "下一页"、"继续" | currentPage +1，保持 pageSize |
| "上一页"、"返回" | currentPage -1（最小为1） |
| "第N页" | currentPage = N |
| "查看全部" | pageSize 设为最大值 100，currentPage = 1 |
| "查看详细信息" | 切换详细模式，保持其他参数 |
| "查看简单信息" | 切换简单模式，保持其他参数 |

**重置触发**：用户使用"新的/重新/重置"等关键词，或输入全新查询条件时重置上下文。

## 错误处理

### 场景一：查询条件过于宽泛

当用户查询条件过于宽泛（如仅"查询服务器"无任何过滤条件），建议引导补充筛选条件，例如：

```markdown
当前查询条件较为宽泛，共查询到 N 台服务器。

您可以补充以下任一条件缩小范围：
- **机房**：如"贵州"、"北京"、"上海"
- **状态**：如"在线"、"库存"
- **类型**：如"物理机"、"虚拟机"
- **IP**：内网IP或公网IP
```

### 场景二：无查询结果

```markdown
## 查询结果

未查询到符合条件的服务器。

可用机房：贵州、北京、上海、广州、朝阳
```

### 场景三：MCP 工具调用失败

当 MCP 工具返回错误（网络异常、服务不可用、超时等），返回错误信息：

```markdown
## 查询失败

**错误类型**：MCP 服务异常

**错误原因**：{MCP 工具返回的错误信息，如"网络连接失败"/"API 请求超时"}

**建议**：请稍后重试，如问题持续请联系管理员。
```
