# Apollo 应用可选值列表

> 本文档维护 Apollo 配置中心中的常见应用列表，用于用户输入到 AppId 的映射。
> 当用户输入无法匹配到以下列表时，原值传递给 API。

---

## 使用说明

1. **匹配规则**：用户输入的应用名称与上表"应用名称"列做包含匹配（like）
2. **匹配成功**：取对应的 AppId 传递给 API
3. **匹配失败**：将用户输入原值传递给 API，由 Apollo 进行模糊匹配
4. **动态获取**：线上应用以 MCP 工具 `apollo_app_list` 返回为准；下表为常见示例，供映射参考
5. **更新时机**：当 Apollo 中新增或下线应用时，同步更新本表
