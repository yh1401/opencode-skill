## 使用规则

1. **优先动态获取**：用户未明确指定时，先调用 `apollo_host_list` 查看全部可用环境
2. **关键词匹配**：用户提到地名/产品名时，按上表映射到环境名称，作为 `hostName` 参数传入 `apollo_config_query`
3. **多套命中**：一个关键词命中多套（如"小A平台"）时，列出候选让用户确认
4. **默认兜底**：无法匹配时，不传 `hostName`，使用 MCP 默认环境（`APOLLO_HOST_NAME` 配置或第一条）
5. **更新时机**：第三方接口返回环境变化时，同步更新本表
