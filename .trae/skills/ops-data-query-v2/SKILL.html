📋 概述

Skill Agent 是一个基于 MCP (Model Context Protocol) 的智能代理系统，支持多种查询技能的统一管理和调用。专为 Dify 平台 设计，可直接上传使用。

🚀 核心特性

  • 支持 HTTP 接口：通过 http://localhost:3001/api/v2/cmdbServer/getCmdbServerBaseMessageList 获取真实 CMDB 数据
  • cmdb-server-query 技能：采用真实 HTTP 接口调用，不依赖 Mock 数据
  • 动态参数构建：支持字段可选值获取和动态参数构建
  • 结果分析：支持查询结果的统计分析
  • Excel导出：支持将结果导出为Excel格式

🎯 技能路由说明

核心规则

子技能采用平行匹配机制，基于用户输入的整体语义和各技能的功能定位进行智能匹配，而非单纯依赖关键词优先级。

技能功能定位

技能功能定位典型场景状态
project-deployment-query项目部署信息查询查询部署记录、状态、版本、环境✅
server-public-ip-query服务器公网IP查询查询公网IP、带宽、网络类型✅
project-basis-query工程项目基础信息查询查询项目代码仓库(SVN/GIT)、项目属性✅
cmdb-server-queryCMDB服务器查询查询服务器配置、机房位置、运行状态，通过真实HTTP接口获取数据✅
product-query产品信息查询查询产品名称、ID、启用状态✅

匹配策略

系统采用语义理解 + 功能匹配的双重策略：

  1. 意图识别：分析用户查询的核心目的（如"查询部署"、"查找IP"、"获取产品信息"）
  2. 功能匹配：根据各技能的功能定位，选择最匹配的技能执行查询
  3. 并行候选：支持多技能并行候选评估，选择置信度最高的技能

匹配示例

  • "查询guizh-rules-api的部署记录" → project-deployment-query（部署信息查询）
  • "查询贵州机房的公网IP" → server-public-ip-query（公网IP查询）
  • "查询服务器配置信息" → cmdb-server-query（服务器资源查询）
路由逻辑详情：ROUTING.md

🚀 快速开始

在 Dify 中使用

  1. 启动 MCP 服务器（提供真实数据）： 
    cd mcp_server
PORT=3001 npm start
  2. 将整个 skill-agent 目录打包为 skill-agent.zip
  3. 在 Dify 的 skill-agent 管理页面上传 skill-agent.zip
  4. 系统自动解析 registry/skills.json 加载所有技能
  5. 即可使用所有已启用的技能

🔌 API 信息

CMDB 服务器查询 API（cmdb-server-query - HTTP接口）

主接口（本地 MCP 服务器）：

端点: POST http://localhost:3001/api/v2/cmdbServer/getCmdbServerBaseMessageList
Content-Type: application/json
认证: 无需认证（开发/测试环境）
状态值: 0-在线, 1-库存, 2-计划上线, 3-维修中, 4-已报废, 5-待分配
环境值: 1-测试, 2-生产, 3-灰度, 4-研发

请求示例：

{
  "belong": 2,
  "hostName": "prod-guizhou-api",
  "node": "云公司->贵州",
  "state": "0",
  "osType": "linux",
  "currentPage": 1,
  "pageSize": 15
}

➕ 扩展新技能

只需 3 步即可添加新技能：

第一步：创建目录结构

skills/
└── new-skill/              # 新技能目录
    ├── SKILL.md           # 技能定义（必填）
    ├── config/params.yaml  # 参数配置（可选）
    └── references/        # 参考文档（可选）

第二步：编写 SKILL.md

# 新技能（new-skill）

## 1. When to Activate（触发条件）
当用户查询**XXX**相关信息时触发此技能。

## 2. How It Works（执行流程）
1. 意图识别 → 识别为XXX查询
2. 参数提取 → 提取查询条件
3. API调用 → 调用 XXX 接口
4. 数据处理 → 格式化返回结果

## 3. Examples（示例）
**输入**："查询XXX信息"
**输出**：返回符合条件的数据列表

第三步：注册技能

在 registry/skills.json 的 skills 数组中添加：

{
  "id": "new-skill",
  "name": "新技能名称",
  "description": "技能功能描述",
  "enabled": true,
  "path": "skills/new-skill/SKILL.md",
  "keywords": ["关键词1", "关键词2", "关键词3"],
  "version": "1.0.0"
}

注册中心字段说明

字段必填说明
id✅技能唯一标识（英文、短横线）
name✅技能显示名称（中文）
description✅一句话功能描述
enabled✅是否启用（默认 true）
path✅SKILL.md 相对路径
keywords✅3-5个中文关键词
version建议版本号（可选）

详细步骤请参阅：新增技能快速参考

🏗️ 架构说明

├── mcp/                        # MCP API 定义文档
└── tests/                      # 测试用例

数据流

用户输入 → 意图识别 → 技能路由 → 参数校验 → 子技能处理 → MCP调用 → 结果格式化 → 返回

参数转换流程

用户输入 → 条件提取 → 字段映射 → 操作符转换 → API参数构建 → 调用执行 → 后置过滤 → 返回

错误处理流程

API调用失败 → 返回错误信息 → 记录错误日志
