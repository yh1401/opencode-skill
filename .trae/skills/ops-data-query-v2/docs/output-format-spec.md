# 技能输出格式参考

本文档说明各技能的推荐输出格式。**LLM 可根据查询结果和场景自主选择合适的展示方式**（表格、列表、摘要均可），不必严格绑定 Markdown 表格。

---

## 通用规范

| 规范项 | 建议 |
|--------|------|
| **结果概览** | 最前面简要说明查询到的数量 |
| **关键字段** | 突出显示用户最关心的字段（加粗或前置） |
| **日期格式** | 统一 `YYYY-MM-DD HH:mm:ss` |
| **空结果** | 返回友好提示：`未查询到符合条件的记录` |
| **数量少（≤5条）** | 展示完整详情 |
| **数量多（>5条）** | 表格展示 + 可选的结果分类汇总 |

---

## 各技能关键字段说明

| 技能 | 关键字段（展示时优先） |
|------|----------------------|
| cmdb-server-query | 主机名、IP、状态、机房、操作系统、配置（CPU/内存/磁盘） |
| server-public-ip-query | 公网IP、内网IP、机房、带宽、带宽类型 |
| product-query | 产品名、产品级别、所属部门、产品经理、运维负责人 |
| project-deployment-query | 项目名称、环境、状态、版本、部署时间、负责人、耗时 |
| project-basis-query | 项目名、中文名、所属产品、SVN/GIT路径、项目类型 |

---

## 空结果 & 错误格式

**空结果：**
```
未查询到符合条件的记录，请尝试调整查询条件。
```

**查询失败：**
```
查询失败：[错误描述]
请稍后重试。
```
