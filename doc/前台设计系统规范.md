# 视联 AI 运维平台 · 前台设计系统规范（v1.0 提案）

| 项目 | 内容 |
|---|---|
| 适用范围 | `ai-ops/platform/frontend`（React 18 + AntD 5 + Vite） |
| 设计基调 | **浅色、克制的苹果式工作台**：灰阶分层 + 单一蓝强调 + 药丸状态色 |
| 技术落点 | AntD 5 `ConfigProvider.theme` 全局 token + `src/styles.css` 基础层 + 1 个 `StatusPill` 小组件 |
| 不做什么 | 不做大块深色、不做玻璃拟态堆叠、不做渐变文字、不做重投影 |
| 版本 | 2026-10-30 提案（待评审）；2026-11-05 吸收原 `design-system-preview.html` 预览稿要素（预览文件已删除），新增附录二 |

---

## 一、设计原则

1. **灰阶承担层次，颜色只做强调**（60-30-10）：60% 画布灰、30% 白面与文字、10% 主色。主色只出现在主按钮、链接、选中态、焦点环，其余一律中性。
2. **靠底色差与极淡阴影分层，不靠边框**：卡片无边框；只有表格分隔线、区块内分隔用 1px 发丝线。
3. **状态永远"药丸 + 圆点"**，不用高饱和整块填色；颜色永远不单独承载语义，必须配文字。
4. **密度优先但不挤**：4pt 栅格，表格行高 40 / 卡片内边距 16~20；用"留白 + 字重"做层级，而非加粗放大。
5. **光感统一**：所有圆角、阴影、动效曲线来自同一套尺度，禁止页面自行发明数值。

## 二、颜色系统

### 2.1 基础色板（Primitives）

只允许使用下表色值，页面不得出现未被引用的十六进制。

| 角色 | 名称 | 色值 | 用途 |
|---|---|---|---|
| 画布 | `canvas` | `#F5F5F7` | 内容区背景、侧栏底色 |
| 白面 | `surface` | `#FFFFFF` | 卡片、抽屉、弹窗 |
| 弱面 | `surface-subtle` | `#FAFAFC` | 表头、隔行、卡内嵌区 |
| 发丝线 | `hairline` | `#E5E5EA` | 表格行分隔、区块分隔 |
| 强分隔 | `hairline-strong` | `#D2D2D7` | 输入框描边、次要按钮描边 |
| 正文 | `text-primary` | `#1D1D1F` | 标题、正文、表格主数据 |
| 次级 | `text-secondary` | `#6E6E73` | 标签名、说明文字、占位符 |
| 三级 | `text-tertiary` | `#86868B` | 辅助元信息、单位 |
| 禁用 | `text-disabled` | `#AEAEB2` | 禁用文字、空状态图标 |

> 中性色带极轻微冷调（偏蓝 1~2%），与主色同调，避免"死灰"。

### 2.2 主色（Primary · Apple 蓝）

| 角色 | 色值 | 用途 |
|---|---|---|
| `primary` | `#0071E3` | 主按钮、链接、选中态、焦点环 |
| `primary-hover` | `#0077ED` | 悬停 |
| `primary-active` | `#0062C4` | 按下 |
| `primary-soft` | `#EAF3FF` | 选中背景、信息块底 |

### 2.3 语义色（药丸三件套：底色 / 文字 / 圆点）

| 语义 | 药丸底 | 药丸文字 | 圆点/图标 |
|---|---|---|---|
| 成功 / 健康 | `#E9F6EC` | `#1D7A32` | `#34C759` |
| 风险 / 危险 | `#FFEBEA` | `#C41E1A` | `#FF3B30` |
| 警告 / 无数据 | `#FFF4E5` | `#A05A00` | `#FF9F0A` |
| 信息 / 提示 | `#EAF3FF` | `#0056B3` | `#0071E3` |
| 中性 / 未触发 | `#F2F2F5` | `#6E6E73` | `#8E8E93` |

**规则**：药丸 = 底色 + 12px/500 文字 + 999 圆角 + 20px 高，**无描边**；禁止 `<Tag color="red">` 这种高饱和实底写法。

### 2.4 语义映射（对齐现有业务口径）

| 现有类名 | 语义 | 新规范 |
|---|---|---|
| `.verdict-RISK` | 风险 | 药丸「风险」+ 红点；详情行文字用 `risk-text` |
| `.verdict-NO_DATA` | 无数据 | 药丸「无数据」+ 橙点 |
| `.verdict-NOT_TRIGGERED` | 未触发 | 药丸「未触发」+ 灰点 |
| `.verdict-NOT_APPLICABLE` | 不适用 | 药丸「不适用」+ 蓝点 |
| 菜单「部分」 | 部分实现 | 橙色药丸（小号 18px） |
| 菜单「规划」 | 规划中 | 中性药丸（小号 18px） |
| 菜单「已实现」 | 完成 | **不显示标签**（缺省即正常） |

### 2.5 对比度要求

| 场景 | 最低 | 本规范取值 |
|---|---|---|
| 正文 / 表格值 | 4.5:1 | `#1D1D1F` on `#FFFFFF` ≈ 17:1 |
| 次级文字 / 占位符 | 4.5:1 | `#6E6E73` on `#FFFFFF` ≈ 5.0:1（**不得使用 `#AEAEB2` 作占位符**） |
| 药丸文字 | 4.5:1 | 各语义深色均 ≥ 5:1 |
| 控件描边 / 图标 | 3:1 | `#D2D2D7` 仅用于非唯一识别描边，关键图标用 `#6E6E73` |
| 焦点环 | 3:1 | `#0071E3` 3px 外环 |

> 上线前用 WebAIM Contrast Checker 复核全部药丸组合；色盲场景下状态必须含文字，不得只靠红/绿点区分。

## 三、字体系统

### 3.1 字体族

```css
--font-sans: -apple-system, BlinkMacSystemFont, 'SF Pro Text', 'SF Pro Display',
  'PingFang SC', 'Helvetica Neue', 'Microsoft YaHei', sans-serif;
--font-mono: 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace;
```

- 中文回退 `PingFang SC`，Windows 回退 `Microsoft YaHei`；不引入外链字体（避免 CI/内网环境闪烁）。
- 所有数字列（ID、IP、耗时、统计值）启用 `font-variant-numeric: tabular-nums`。

### 3.2 字号阶梯（6 级，禁止新增）

| 层级 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| `title-page` | 20 / 28 | 600 | 页头标题（原 H5 14px 偏小，需放大） |
| `title-section` | 16 / 24 | 600 | 卡片标题、区块标题 |
| `body-strong` | 14 / 22 | 600 | 表头、字段名、关键数值 |
| `body` | 14 / 22 | 400 | 正文、表格值、表单项 |
| `caption` | 13 / 20 | 400 | 说明、辅助列、单位 |
| `micro` | 12 / 18 | 400 | 药丸文字、时间戳、代码块 |

- 字重只用 **400 / 500 / 600**；不再出现 700（apple 式层级靠尺寸与留白，不靠粗）。
- 标题字距 `-0.01em`，正文 `0`，全大写英文段落 `+0.04em` 且仅用于极短标签（不推荐）。
- 统计数字（`Statistic`）用 24/32、600、`tabular-nums`，标签用 `caption`。

### 3.3 排版细则

- 段落最大行宽 72 字符（表格/代码除外）。
- 中文与英文/数字之间保留原生空格，不手动插空格。
- 代码、IP、host、appId、JSON 一律 `.mono` 12/18 + `#1D1D1F`，承载在 `surface-subtle` 底、`8px` 圆角、`8px/12px` 内边距。

## 四、间距系统（4pt 栅格）

### 4.1 间距标尺

| Token | 值 | 用途 |
|---|---|---|
| `space-1` | 4 | 图标与文字、圆点与标签 |
| `space-2` | 8 | 按钮组、工具栏元素间距、表单项内间距 |
| `space-3` | 12 | 卡片内元素间距、表格单元格纵向 |
| `space-4` | 16 | 卡片间距、卡片内边距（紧凑）、区块间距 |
| `space-6` | 24 | 页面内边距、卡片内边距（标准）、区块大间距 |
| `space-8` | 32 | 页面上下留白、空状态上下留白 |
| `space-12` | 48 | 空状态、引导区 |

**禁止**：出现 5/10/14/18/20/28 等标尺外数值（现有 `padding: 16px` 内容区、`gap: 12px` 保留为规范值）。

### 4.2 页面级

| 项 | 值 |
|---|---|
| 侧栏宽度 | 232（现 224，+8 让菜单文字更舒展；窄屏 200） |
| 页头高度 | 56 |
| 内容区内边距 | 24（<1280px 时 16） |
| 卡片间距（grid gap） | 16 |
| 页面纵向区块间距 | 24 |

### 4.3 组件级

| 组件 | 值 |
|---|---|
| 卡片 | 内边距 20（`Card size="small"` 16）；标题与内容间距 12 |
| 表格 | 表头高 40；行高 40（紧凑 36）；单元格左右 12，上下 10；表格与工具栏间距 12 |
| 工具栏 | 元素 gap 8；与下方内容 12 |
| 表单 | label 与控件 4；表单项间距 16 |
| 抽屉 | 头部 56；内容 24；底部 16 |
| 药丸 | 高 20，左右 8，圆角 999 |
| 按钮 | 高 34（默认），左右 16；仅图标按钮 32×32（点击热区用伪元素扩到 44） |

### 4.4 响应式

- 容器查询优先（组件按所在盒子宽度自适应），页面级断点只保留：`≥1440` 宽松 / `1024–1440` 标准 / `<1024` 紧凑（侧栏折叠为图标）。
- 统计卡用 `repeat(auto-fit, minmax(180px, 1fr))`，不写死列数。

## 五、层次（Elevation）与材质

### 5.1 四级表面

| 层级 | 组件 | 底色 | 圆角 | 阴影 |
|---|---|---|---|---|
| L0 画布 | 内容区、侧栏 | `canvas` `#F5F5F7` | — | 无 |
| L1 卡片 | Card、统计块、图区 | `surface` `#FFFFFF` | 12 | `xs` |
| L2 浮层 | Drawer、Modal | `surface` | 16 | `md` |
| L3 瞬时 | Popover、Tooltip、Message | `surface` | 10 | `lg` |

### 5.2 阴影标尺

```css
--shadow-xs: 0 1px 2px rgba(0, 0, 0, 0.04);
--shadow-sm: 0 2px 8px rgba(0, 0, 0, 0.05);
--shadow-md: 0 8px 24px rgba(0, 0, 0, 0.08);
--shadow-lg: 0 16px 48px rgba(0, 0, 0, 0.12);
```

原则：**看得见的阴影就是过头了**；L1 卡片默认只用 `xs`，悬停不加深，只有"可点击卡片"才升到 `sm`。

### 5.3 边框规则

- 卡片：**无边框**，靠 `canvas` ↔ `#FFFFFF` 差值 + `xs` 阴影分层。
- 表格：仅横向发丝线 `hairline`，表头底 `surface-subtle`，无竖线。
- 输入框：`hairline-strong` 1px；聚焦改 `primary` 1px + 3px `rgba(0,113,227,0.25)` 焦点环。
- 禁止"卡中卡"；卡内分区用 12px 留白 + 发丝线分隔。

### 5.4 圆角标尺

| Token | 值 | 用途 |
|---|---|---|
| `radius-sm` | 8 | 输入框、按钮、代码块 |
| `radius-md` | 12 | 卡片、图区 |
| `radius-lg` | 16 | Drawer、Modal、侧栏选中块用 8 |
| `radius-pill` | 999 | 药丸、头像、Segmented 滑块 |

### 5.5 z-index 阶梯

`10 粘性表头 / 100 下拉 / 200 固定页头 / 1000 抽屉 / 1100 全局提示 / 1200 气泡`。禁止任意整数。

### 5.6 动效

- 时长 150ms（微交互）/ 200ms（浮层进出）；曲线 `cubic-bezier(0.2, 0, 0, 1)`。
- 只做位移与透明度（8px 以内），不做缩放弹跳、不做毛玻璃堆叠。
- 必须响应 `prefers-reduced-motion: reduce`（去掉过渡）。

## 六、组件规范

| 组件 | 规范要点 |
|---|---|
| **主按钮** | `#0071E3` 白字、radius 8、高 34；悬停 `#0077ED`；**一屏最多 1 个主按钮** |
| **次按钮** | 白底 + `hairline-strong` 描边 + 正文色；悬停底 `#F5F5F7` |
| **文字按钮** | 主色文字，无底色；危险操作用 `#C41E1A` 文字 |
| **表格** | 见 5.3；行悬停 `#F5F7FA`；选中行 `primary-soft`；操作列用文字按钮，不用图标堆叠 |
| **分段控件** | 用 `Segmented` 替代 Tabs 做同页视图切换：底 `#F0F0F3`、滑块白 + `xs` 阴影 |
| **抽屉** | 左圆角 16、头部 56、底部按钮右对齐；宽度：详情 480、表单 640 |
| **状态药丸** | 见 2.3；列表内左侧对齐、固定 20 高，避免行高跳动 |
| **空状态** | 线性图标 40px `text-disabled` + `caption` 说明 + 一个文字按钮；禁止插画占位 |
| **骨架屏** | 列表/详情统一 `Skeleton`，替代裸 `Spin`；仅首屏加载用 |
| **表单** | 标签在上（非横排），必填用主色星号；错误文案 `risk-text` 12px 紧跟控件下方 4px |
| **提示** | `Alert` 扁平、底色用语义药丸底、无左侧色条；仅 1 行摘要 + 可展开详情 |

## 七、图表与拓扑

- 画布 `#FAFAFC`，无网格背景；网格线 `#EFEFF4`。
- 节点：白底 + `hairline-strong` 1px + radius 8 + `xs` 阴影；文字 `body` 12/13px。
- 节点选中：2px `primary` 描边 + 4px `rgba(0,113,227,0.12)` 光晕。
- 边：`#D2D2D7` 1px；高亮 `primary`；**线宽不做加粗变化**。
- 状态：只用 6px 圆点（成功/风险/警告/中性）置于节点右上角，不用整块填色。
- **排障/工单状态描边（`tprel/topology_dagre.html` 专用例外）**：按优先级取最高级别，2px 描边 + 虚线区分进行中；`排障中 #e74c3c 虚线` > `工单待处理 #d35400` > `已定位根因 #27ae60` > `工单已解决 #16a085` > `排障失败 #95a5a6 虚线`。这是唯一允许在拓扑中出现的整节点描边，配套文字图例（仅展示 count>0 的级别），确保不单靠颜色承载语义。
- 图例固定左下、`caption` 字号、圆点 + 文字。

### 8.2 基础层（`src/styles.css`）

- 侧栏改浅：`theme="light"`，`background: #F5F5F7`（不再用半透明 + blur，避免与卡片光感冲突）；
- 品牌块：`brand-mark` 底色改 `#0071E3`、半径 8；文字 `#1D1D1F`；

- 删除 `.plan-dot`（已无引用）；
- 新增 `.status-pill`、`.status-dot`、`.mono`、`.shadow-*`、`.stack-*`（间距）等基础类。

### 8.3 新增组件（唯一新增件）

`src/components/StatusPill.tsx`：`{ tone: 'success'|'risk'|'warning'|'info'|'neutral'; label: string; dot?: boolean; size?: 'sm'|'md' }`。全站标签统一走它，替换散落的 `<Tag color=...>`。
